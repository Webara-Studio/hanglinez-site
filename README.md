# Hanglinez site

A mobile-first static marketing site for Hanglinez Ghana: collapsible drying clothesline racks with delivery and installation across Greater Accra and Kumasi.

## Verified facts used

- Business: Hanglinez
- Product: collapsible drying clothesline rack
- Service: production, delivery and installation
- Service areas: Greater Accra and Kumasi, Ghana
- Phone / WhatsApp: +233 54 640 5275
- Email: hanglinezfd@gmail.com
- Tagline direction: “fold away”

## Asset note

`public/assets/hanglinez-product-reference.jpg` and `hanglinez-wordmark-reference.jpg` are crops from the client-approved Facebook page screenshot. `facebook-profile-image.jpg` is the publicly exposed Facebook image downloaded during discovery. The supplied installation/product images are cleaned crops in `assets/hanglinez-gallery/` and are used in the hero and gallery. Replace reference crops with original logo/product files when supplied; do not upscale them for print use.

## Run locally

This is dependency-free static HTML/CSS/JS. Serve the repository root with any static server, for example:

```bash
python3 -m http.server 4173
```

The first release deliberately uses WhatsApp and telephone conversion rather than invented e-commerce pricing, inventory or specifications.

## Deployment note

A sitemap should be added once Hanglinez confirms its production domain. No live domain is assumed in this repository.
